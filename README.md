### 👋 안녕하세요

----
저는 변화하는 업무 규칙을 안정적인 API와 예측 가능한 시스템 동작으로 구현하는 Java/Spring 백엔드 개발자입니다.  
저는 견고한 도메인 모델, 트래픽과 기능의 증가를 감당하는 아키텍처, 그리고 장애에도 안정적으로 운영되는 시스템에 관심이 많습니다. 🚀

#### ☕ 백엔드
Java와 Spring을 중심으로 API, 배치, 비동기 처리 시스템을 개발합니다. 요구사항을 곧바로 코드에 옮기기보다 도메인 규칙과 상태 흐름을 먼저 정의하고, 변경 영향이 제한되는 구조를 지향합니다.

#### ⚡ 비동기 처리와 시스템 연동
Spring WebFlux, RabbitMQ, Debezium, Transactional Outbox를 활용해 장시간 작업과 외부 시스템 연동을 요청-응답 흐름에서 분리합니다. 실패와 재시도, 중복 처리까지 고려하며 용도에 따라 REST API와 WebSocket의 역할을 구분합니다.

#### 🗄️ 데이터
PostgreSQL을 주로 사용하며 Redis, Oracle, MSSQL도 다룹니다. 트랜잭션 범위, 실행 계획, 인덱스와 데이터 접근 패턴을 기준으로 데이터 정합성과 성능을 함께 고려합니다.

#### ☁️ 인프라와 운영
AWS와 GCP 환경에서 Docker로 API 서버, 데이터베이스, 캐시, 메시지 브로커를 구성하고 배포할 수 있습니다. Nginx와 Apache를 활용한 리버스 프록시·멀티도메인 구성과 Tomcat 기반 애플리케이션 운영 경험이 있습니다.

#### 🤖 AI 연동과 웹 개발
Python, FastAPI, XGBoost를 활용해 예측 모델을 개발하고 Java/Spring 백엔드와 연동한 경험이 있습니다. 백엔드를 중심으로 개발하지만 React와 TypeScript를 사용해 API 기반 웹 화면도 구현할 수 있습니다.
