### 👋 안녕하세요! 백엔드 개발자 하태욱입니다.

복잡한 비즈니스 요구사항을 **변경에 유연한 구조로 설계**하고, 서로 다른 시스템을 안정적으로 연결하는 일에 관심이 많습니다.  
주로 **Java와 Spring**을 사용하며, 기능 구현뿐 아니라 **유지보수성, 데이터 정합성, 성능과 장애 대응**을 함께 고려합니다. 🚀

### ☕ 백엔드 개발에서는,

**Java와 Spring Boot**를 중심으로 API와 비즈니스 로직을 개발합니다.  
객체지향 설계와 디자인 패턴을 활용해 복잡한 업무 규칙을 구조화하며, **설정 기반 정책 엔진과 다단계 결재 시스템**을 설계·개발한 경험이 있습니다.

### ⚡ 시스템 연동과 비동기 처리에서는,

데이터 동기화부터 실시간 제어까지 시스템 특성에 맞게 **Batch, WebSocket, 이벤트 기반 메시징**을 활용합니다.  
장시간 AI 작업을 **Job 기반 비동기 처리**로 분리하고, API 서버와 Worker의 역할을 나눠 설계한 경험이 있습니다.

### 🗄️ 데이터와 인프라에서는,

**PostgreSQL**을 주로 사용하며 **Oracle, MSSQL** 환경에서도 개발했습니다.  
실행 계획 분석, 인덱싱, 파티셔닝으로 데이터 처리 성능을 개선하고, **Redis**를 이용한 캐싱과 상태 관리도 다룹니다.  
**Docker, Nginx, AWS, GCP**를 활용해 서비스를 배포하고 테스트·운영 환경을 구성한 경험이 있습니다.

### 🤖 AI 기반 개발 환경에서는,

**Claude Code와 OpenAI Codex**를 활용해 코드 구현과 리뷰를 역할별로 분리합니다.  
**Context Engineering**으로 프로젝트 구조와 개발 규칙을 AI Agent에 전달하고, **Multi-Agent Workflow**를 개인 프로젝트에 적용하며 **구현 → CI 검증 → 코드 리뷰** 흐름을 개선하고 있습니다.  
**Harness Engineering과 Agent Orchestration**에도 관심을 가지고 있습니다.

### 🧠 AI 모델과 서비스 연동에서는,

**Python과 XGBoost**로 수요예측 모델을 개발하고, **FastAPI와 Spring**을 통해 서비스에 연동한 경험이 있습니다.  
생성형 AI API의 긴 실행 시간과 **Rate Limit**을 고려해 동시성 제어와 재시도 흐름을 구성했습니다.  
**Kotlin과 Jetpack Compose**를 활용한 Android 개발도 개인 프로젝트에서 진행하고 있습니다.
